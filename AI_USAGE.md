AI Usage

AI tools were used during the development of ShiftSwap to assist with implementation, debugging, and UI improvements.

Areas Where AI Was Used
- Understanding the requirements and planning the application workflow.
- Assistance with React UI development and styling.
- Help with Flask API implementation and shift validation logic.
- Debugging errors and improving the overall user experience.

Changes and Decisions
AI suggestions were reviewed and adapted to fit the project requirements. The interface and implementation were refined during development, and the main workflows were tested to verify their behaviour.

AI was used as a development aid, with final implementation and testing decisions made based on the application's requirements.

Technology Stack
- React and Vite
